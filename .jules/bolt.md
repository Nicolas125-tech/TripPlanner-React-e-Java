## YYYY-MM-DD - Implement backend pagination
**Learning:** Returning Spring Data `PageImpl<T>` from a REST controller in Spring Boot 3.2 without `spring-data-web` properly configured or registered via Jackson Modules (e.g., `PageJacksonModule`) results in an `HttpMessageNotWritableException` because `Pageable.unpaged()` causes recursive serialization issues. Using `@SpringBootTest` with `@AutoConfigureMockMvc` in test suites automatically sets up the correct Jackson serializers compared to `@WebMvcTest`.
**Action:** When refactoring to `Page<T>` responses, update test controllers to use `@SpringBootTest` + `@AutoConfigureMockMvc` if MockMvc tests fail with Jackson serialization errors. Always implement the corresponding UI components (or temporarly increase the `@PageableDefault` size) to prevent unexpected data truncation in the frontend client.
