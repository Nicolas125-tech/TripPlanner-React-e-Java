💡 What
Implemented proper debouncing for `sessionStorage` writes in `TripContext.jsx` using the `debounce` utility, replacing naive `setTimeout(..., 0)` calls. Also fixed broken tests in `App.test.jsx` by wrapping the component in `TripProvider`.

🎯 Why
Previously, rapid state updates (like toggling favorites quickly) queued multiple `setTimeout` macro-tasks, causing redundant JSON serialization and blocking the main thread. This optimization prevents that by coalescing rapid updates.

📊 Impact
Reduces unnecessary I/O and JSON serialization operations, preventing main thread freezing during rapid interactions.

🔬 Measurement
Verify that rapidly clicking the favorite button multiple times only triggers a single write to `sessionStorage` after the user stops clicking, rather than writing on every single click.
