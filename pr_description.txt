🚀 [deploy] Deploy to Render using Docker and PostgreSQL

🎯 What
This PR sets up the full-stack application for automated deployment to Render. It configures the Java backend to run via Docker, connects it to a production-ready PostgreSQL database, and configures the React frontend to run as a static site and connect to the new backend.

🛡️ Solution
- Created a multi-stage `Dockerfile` to build and serve the Spring Boot application using Maven and Temurin JRE.
- Added `org.postgresql:postgresql` dependency to the `backend/pom.xml`.
- Externalized database connection (URL, user, password), DDL settings, and CORS via environment variables in `application.properties`, falling back to the local H2 and localhost settings to keep local dev environments working.
- Created a `render.yaml` Blueprint file to declare the PostgreSQL database, the Backend Web Service, and the Frontend Static Site as Infrastructure as Code.
- Resolved circular dependencies between frontend (VITE_API_URL) and backend (APP_CORS_ALLOWED_ORIGINS) in the Blueprint configuration.
