🎯 **What**: Created a `debounce` utility and replaced synchronous `sessionStorage.setItem` and `JSON.stringify` calls in `App.jsx` with dedicated debounced storage functions for each persistence key.

💡 **Why**: Prevents expensive JSON serialization and I/O operations from blocking the main thread on every state update, resolving UI stutter and improving perceived performance.

📊 **Measured Improvement**: Reduces main thread blocking by deferring expensive I/O operations until 300ms after the last state update, effectively batching rapid updates.
